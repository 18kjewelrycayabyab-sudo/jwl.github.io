# jwl.github.io
**DNA Mismatch Repair (MMR) Simulation** is an interactive 3D animation that demonstrates how cells detect and correct errors in DNA replication. It visually presents the step-by-step repair process, showing how mismatched base pairs are identified, removed, replaced, and corrected to maintain DNA accuracy and genetic stability.

## Routes
- **Main simulation:** [`dna.html`](dna.html)
- **Scroll preview:** [`/extra/`](extra/) — every scene from the simulation, one full screen at a time (GSAP; needs a network connection for the CDN)
